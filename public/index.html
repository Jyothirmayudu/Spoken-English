Data & backup

All data lives in a real SQLite database file (db/speakpath.db) on the server — that's the source of truth. The button below also saves a full, human-readable JSON copy of everything (every account and every bit of progress, no passwords included) to db/backup.json on disk, and downloads it to you as well — so you always have both a database and a plain JSON backup.

To browse the raw SQLite database directly (tables, rows, everything) with a visual tool, download the free, open-source DB Browser for SQLite app and open the db/speakpath.db file from your project folder.
